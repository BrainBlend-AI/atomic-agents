# Atomic Agents 2.13.0

Draft. Collects what has landed on main since 2.12.1.

## Dependencies

- Instructor is a range again: `instructor>=1.17.0,<2`. The exact pin dated from Instructor 1.9.2 (upstream issue 567-labs/instructor#1796, an import path removed in a patch release) and was bumped by hand ever since. The framework now references `instructor.Instructor` and `instructor.AsyncInstructor` from the package root, which is the only change 1.17.0 needed; the suite passes unchanged otherwise.
- Floors are now true floors: `pydantic>=2.11.4` (the MCP schema transformer passes `__config__` together with `__base__` to `create_model`, allowed since pydantic 2.11.4) and `mcp>=1.8.0,<2` (`mcp.client.streamable_http` first shipped in 1.8.0).
- Two CI jobs guard this: a fresh install of the built wheel that imports every module, and a run of the suite on the lowest allowed version of every runtime dependency. Together they catch the two ways the old pin bit us: an import path removed upstream, and a floor nobody had tested.

## Compatibility

Python 3.12 or newer. Applications that pin `instructor==1.14.5` keep working; applications that move to 1.17.0 need no code change on their side. openai 3.x resolves and passes the suite with Instructor 1.17.0.
