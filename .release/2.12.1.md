# Atomic Agents 2.12.1

## Fixes

- Cap `mcp` below 2.0 so fresh installs can import the MCP connector. The lockfile had hidden the incompatible upstream import change. (#308)
- Give tools, resources, and prompts independent default configurations. Explicitly shared configurations still work. (#307)
- Serialize tool arguments with Pydantic's JSON representations, including dates, UUIDs, decimals, paths, enums, and JSON-only field serializers. (#312)
- Complete sync and async streaming for output schemas with field aliases without a validation error. (#314)
- Preserve dictionary arguments and structured results in MCP tools, and validate typed dictionary values. (#313)
- Make the README context-provider example runnable without an undefined typing import. (#311)
- Correct the manual OpenTelemetry setup and document the masking boundary. (#309)

## Forge tools

These downloadable tools live in the repository and are not bundled in the PyPI package.

- Count elapsed time across daylight-saving transitions in DateTimeTool. (#315)
- Apply the requested arXiv category to the full search expression. (#316)

## Installation checks

A new CI job builds the wheel, installs it without the lockfile, and imports every core subpackage.

## Compatibility

Python 3.12 or newer. Instructor remains pinned to 1.14.5 in this patch. The separately tested Instructor range update follows in 2.13.0. MCP 2.x support is still pending.
