# Atomic Agents 2.12.1

Patch release. No framework behavior changes.

## Fix

- Pin `mcp` below 2.0. A fresh `pip install atomic-agents` since late July resolved mcp 2.x, and `import atomic_agents.connectors.mcp` then failed with `ImportError: cannot import name 'streamablehttp_client'`. The repo lockfile kept resolving mcp 1.22, which is why the test suite never saw it. The mcp 2.x migration is scheduled for 2.13.0.

## CI

- New job builds the wheel, installs it into a clean environment without the lockfile, and imports every module under `atomic_agents`. This is the check that would have caught the break before release.

## Compatibility

Python 3.12 or newer. Projects already pinning `mcp<2` or resolving 1.x see no change. Projects that need mcp 2.x should wait for 2.13.0.
